# AI Instructions - Command Documentation

## IMPORTANT FOR ALL AI ASSISTANTS

When you complete tasks that involve running commands, scripts, or workflows:

### Required Actions

1. **Document Commands Immediately**
   - If you run a command that works, add it to `.useful_commands/` directory
   - Create a new `.txt` file or update an existing one
   - Include a brief description of what the command does

2. **File Location**
   - Add commands to: `.useful_commands/<category>_commands.txt`
   - If no category file exists, create one (e.g., `training_commands.txt`, `backtest_commands.txt`)

3. **Documentation Format**
   ```
   ## Feature/Task Name

   # Description
   actual-command-here

   # Multi-step workflows
   command1 && command2
   ```

4. **Check Existing Files First**
   - Before creating a new file, check if relevant commands already exist
   - Use `ls .useful_commands/` or browse the directory
