| Abbrev | Full Term | Definition |
|--------|-----------|------------|
| **OB** | Order Block | Supply/demand zone from last opposing candle before impulse |

| **SFP** | Swing Failure Pattern | False breakout of swing high/low → reversal |
| **BB** | Breaker Block | Failed OB breaching opposite side → reverse polarity |

| **RB** | Rejection Block | Candle strongly rejecting from OB/FVG with inducement |
| **LQ** | Liquidity Void | Low-volume zone where price accelerates |
| **HVI** | High Volume Imbalance | Highest-volume OB in a sequence |
| **IPDA** | Interbank Price Delivery Algorithm | ICT's theory of institutional price delivery |
| **POI** | Point of Interest | Zone where multiple SMC elements converge |
| **SIBI** | Sellside Imbalance Buyside Inefficiency | FVG from aggressive selling needing fill |

| **PDA** | Price Delivery Array | ICT's term for SMC structural level |
