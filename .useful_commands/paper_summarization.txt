## PAPER SUMMARIZATION

# Summarize research papers using LLM (via paper2md tool)
# Requires: OpenRouter API key
# Model: deepseek/deepseek-v4-flash (DeepSeek V4 Flash - fastest and strongest)
cd useful_resources\useful_repos\research-tools\paper2md
uv run python summarize_md_papers.py --papers-dir ..\..\..\papers_md --out output\SENTIMENT_ANALYSIS_SUMMARY.md

# Clear cache and re-run (force re-summarization)
uv run python summarize_md_papers.py --papers-dir ..\..\papers_md --out output\SENTIMENT_ANALYSIS_SUMMARY.md --clear-cache

# Output location: useful_resources\useful_repos\research-tools\paper2md\output\SENTIMENT_ANALYSIS_SUMMARY.md
# Copied to: useful_resources\papers_md\SENTIMENT_ANALYSIS_SUMMARY.md

## API CONFIGURATION

# Edit .env file in paper2md directory to configure API:
# - OPENAI_API_KEY: Your OpenRouter API key
# - OPENAI_BASE_URL: https://openrouter.ai/api/v1
# - OPENAI_MODEL: Model to use (default: deepseek/deepseek-v4-flash)
