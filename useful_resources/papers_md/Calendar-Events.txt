Page 1: ABSTRACT An event is a piece of news that triggers a change in stock prices. Here, an event study is
Page 1: undertaken to capture the effect of abnormal returns due to an event. The event can affect the stock market in
Page 1: the long term or short term. Event research is relevant to both the efficient market hypothesis and behavioral
Page 1: finance. In this study, we collected data from websites that manage financial and economic data, performed a
Page 1: sentiment analysis, and correlated news article data with changes in a particular companyΓÇÖs stock prices in the
Page 1: stock market. Data were collected from two well-known financial news websites. We observed a correlation
Page 1: between stock prices and news items. An event period of one day was considered for the study. The regression
Page 1: equation determined the relationship between stock returns and polarity and subjectivity. Bayesian model
Page 1: averaging was performed to identify the effects of polarity and subjectivity on stock returns. Time-series data
Page 1: were decomposed into components and detrended via regression. Prominent keywords and their polarity
Page 1: values for a particular day were plotted. An event enhanced some stock returns while adversely affecting
Page 1: other stocks. We found a variation range of -400 to 200 for different company stocks for the selected period.
Page 1: INDEX TERMS Event database, social media data, sentiment analysis, data analytics, event studies.

Page 2: A. BAYESIAN MODEL AVERAGING
Page 2:
Page 2: An analysis is conducted by first selecting the best model
Page 2: based on a particular criterion and then learning about
Page 2: the parameters of the chosen model. Any uncertainties of
Page 2: the model selection process are ignored. Contrary to this
Page 2: approach, Bayesian model averaging (BMA) learns parameters for all candidate models and allows one to select a
Page 2: model with specific posterior probabilities. BMA offers the
Page 2: following advantages over other models:
Page 2: 1) BMA captures the uncertainty of a model.
Page 2: 2) BMA reduces error.
Page 2: 3) BMA retains all model uncertainty until the final stage.
Page 2: 4) BMA continuously adjusts model weights.
Page 2: 5) BMA uses a set of models, which is preferable to using
Page 2: a single model.

Page 14: V. CONCLUSION AND FUTURE WORK
Page 14:
Page 14: Two prominent financial websites, namely, moneycontrol.com and economictimes.com, were scraped to build a calendar of events database. The Python language was utilized
Page 14: to scrape the websites. Time components were decomposed
Page 14: from data, and we found the only trend is present in the
Page 14: data, which was detrended via regression. BMA was applied
Page 14: with linear regression, and we found polarity to be a more
Page 14: significant parameter than subjectivity. We also show that the
Page 14: discovery of coronavirus vaccines is positively affecting the
Page 14: Indian stock market. To summarize, this article contributes to
Page 14: the existing body of knowledge in the following ways:
Page 14: 1) A calendar of events database is created.
Page 14: 2) Insights are derived from the events database with
Page 14: quantitative and qualitative data.
Page 14: 3) We find that the invention of coronavirus vaccines has
Page 14: impacted the stock market.
Page 14: Event studies are a useful means of analyzing the stock
Page 14: market, as stock markets are sensitive to events. Portfolio optimization via event studies can be considered in
Page 14: future enhancements. Further work can also categorize events
Page 14: into the following categories: global, national, sectoral, and
Page 14: company-specific events. One can scrape the other financial
Page 14: websites in the future along with moneycontrol.com and
Page 14: economictimes.com websites.
