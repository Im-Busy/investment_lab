# Backtest Commands

## ML-Enhanced Backtest (Default)
```bash
uv run scripts/backtest_ml_enhanced.py --symbol SPY --strategy vwap
```

## ML-Enhanced Backtest with Date Range
```bash
uv run scripts/backtest_ml_enhanced.py --symbol SPY --strategy vwap --start 2018-01-01 --end 2023-12-31
```

## Compare Different Strategies
```bash
uv run scripts/backtest_ml_enhanced.py --symbol SPY --strategy ema --start 2018-01-01 --end 2023-12-31
```

## Run Baseline (No ML)
```bash
uv run scripts/backtest_ml_enhanced.py --symbol SPY --strategy vwap --no-ml
```

## Simple Technical Baselines vs ML (SPY 2020-2026)
```bash
# Compare RSI(14), MA Crossover 50/200, Buy & Hold vs ML strategy
uv run scripts/backtest_simple_baselines.py
```

## Custom Capital and Risk
```bash
uv run scripts/backtest_ml_enhanced.py --symbol SPY --strategy vwap --capital 50000 --risk-pct 0.02
```

## Export Detailed Results
```bash
uv run scripts/backtest_ml_enhanced.py --symbol SPY --strategy vwap --export-results --output-dir reports
```

## Walk-Forward Validation

```bash
uv run scripts/train_ml_model.py --symbol SPY --walk-forward --n-splits 5
```

## Rules-First Batch Tuning (2026-05-20)

### Phase 1: IS Parameter Sweep (3 batches, run sequentially)

```bash
# Batch 1: Major indices + sector ETFs
uv run scripts/tune_rules_params.py --symbols SPY,QQQ,IWM,XLK,XLF --fast --is-only --workers 5 \
    --json-output outputs/tune_batch1.json --md-output reports/parameter_tuning/batch1.md

# Batch 2: Sectors + commodities + bonds
uv run scripts/tune_rules_params.py --symbols XLE,XLV,GLD,TLT,KO --fast --is-only --workers 5 \
    --json-output outputs/tune_batch2.json --md-output reports/parameter_tuning/batch2.md

# Batch 3: Stocks + crypto + forex
uv run scripts/tune_rules_params.py --symbols JPM,XOM,JNJ,SO,BTC_USD,EURUSD_X --fast --is-only --workers 6 \
    --json-output outputs/tune_batch3.json --md-output reports/parameter_tuning/batch3.md
```
